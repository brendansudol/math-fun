# Math Practice

Flash-card math practice for kids: plus, minus, times and divide facts for 2 through 12.

- **Guided path**: step through each operation, a few numbers at a time, with reviews along the way.
- **Daily bonus**: a challenge that either pushes ahead or goes back to a fact set a kid finds tricky.
- **Choose your own**: Endless, a 60-second Time Trial, or Streak.
- **Profiles**: each kid gets their own progress, points and records, saved in the browser.

## Develop

```bash
npm install
npm run dev
```

Pushing to `main` builds the app and deploys it to GitHub Pages.
